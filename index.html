왜 3개를 만들었나

앱 만들면 시간이 오래 걸려요. 그래서 일단 HTML 1장으로 "내가 매일 뭘 보고 싶은가"를 3가지 화면 구조로 만들어 봤어요. 직접 클릭해 보고 가장 손에 익는 걸 메인으로 굳히고, 나머지 2개는 상황별 보조로 두면 됩니다.

이 데이터는 진짜?

모두 mock_data.js 안의 가짜 데이터예요. 진짜로 연결하려면 (a) Apify로 SNS 데이터 가져와서 SOTDA에 점수 매기고 (b) 결과를 같은 형식의 JSON으로 떨궈서 이 화면이 읽게 하면 됩니다. 그 연결은 다음 단계입니다.

파일은 어디로 저장되나

  • · 리포트 → outputs/reports/{고객}/{날짜}.html
  • · 승인 큐 → outputs/approval_queue/
  • · 학습 자료 (★드롭존) → references/manual_learning/{날짜}/
  • · SNS 원본 → data/sns_raw/{플랫폼}/
  • · 매일 04:00 백업 → backups/{YYYY-MM-DD}/

다음 단계

  1. 3개 중 손에 익는 것 1개 고르기
  2. 고른 것의 색/폰트/배치 미세조정
  3. mock_data.js → 진짜 데이터로 교체 (수동 1회 → 자동화)
  4. Notion DB / GitHub Pages에 매일 자동 발행
